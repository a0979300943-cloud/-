## 1.3 接线总表

### （1）电源分配（星形共地！所有 GND 必须连到同一点）

```
12V 电池+ → 开关 → 保险丝 → ┬→ TB6612#1 VM、TB6612#2 VM（电机动力）
                             └→ 5V/5A 降压 IN+  → 5V → 树莓派 Pin4(5V)
                             └→ 5V/3A BEC IN+  → 5V → 3 个舵机红线
12V 电池- ───────────────────── 全部 GND 共点（驱动/降压/BEC/STM32/树莓派/舵机棕线）

5V/5A 降压输出 → STM32 板 5V 引脚（板载 LDO 自出 3.3V）
STM32 3.3V     → 编码器 VCC（若为 3.3V 款）/ STP23L 逻辑侧参考
STP23L VCC     → 按模块标识接 5V（多数款为 5V 供电，TX 为 3.3V 电平，F407 引脚 5V 容忍）
```

**接线后、插树莓派前必做**：万用表量 5V 降压空载输出，调电位器到 **5.00±0.05V** 再接树莓派，防止过压烧板。

### （2）STM32 引脚总表

| 引脚 | 接到 | 引脚 | 接到 |
|------|------|------|------|
| PA8 | TB6612#1 AIN1（M1正） | PE11 | TB6612#1 AIN2（M1反） |
| PE13 | TB6612#1 BIN1（M2正） | PE14 | TB6612#1 BIN2（M2反） |
| PC6 | TB6612#2 AIN1（M3正） | PC7 | TB6612#2 AIN2（M3反） |
| PA0/PA1 | M1 编码器 A/B | PA6/PA7 | M2 编码器 A/B |
| PB6/PB7 | M3 编码器 A/B | PE5/PE6 | 左/右铲板舵机信号线 |
| PB8 | 摄像头舵机信号线 | PA9(TX)/PA10(RX) | 树莓派 RX/TX（**交叉**） |
| PA2(TX)/PA3(RX) | 左 STP23L RX/TX | PB10(TX)/PB11(RX) | 右 STP23L RX/TX |
| PE3 | 启动按键（另脚接 GND） | PE4/PE7 | 左/右碰撞开关（另脚接 GND） |
| PC8/PC9 | LED(+) / 蜂鸣器(+) | GND | LED、蜂鸣器负极 |

> 串口接线口诀：**STM32 TX → 对端 RX，STM32 RX ← 对端 TX，双方共地。**

### （3）TB6612 接线要点

- 每块板：`VM`=12V，`VCC`=3.3V，`GND`=共地；
- `STBY` 接 **3.3V**（否则驱动休眠，电机完全不转）；
- `PWMA/PWMB` 接 **3.3V 常使能**——本设计用 IN 引脚直接输入 10kHz PWM（一相给 PWM、另一相给 0 实现正反转）；
- AO1/AO2、BO1/BO2 接电机两根线，转向反了就对调电机线；
- VM 两端并 100–470µF 电解电容（防电压跌落导致树莓派重启）。

## 1.4 接线完成检查清单（上电前逐项打勾）

- [ ] 万用表通断档：电池正负极**不短路**
- [ ] 所有模块 GND 连通共点
- [ ] 5V 降压未接负载时已调到 5.00V
- [ ] TB6612 的 STBY、PWMA/PWMB 已接 3.3V
- [ ] 编码器、舵机、传感器供电电压与模块丝印一致
- [ ] 两根串口均为 TX/RX 交叉
- [ ] PE3/PE4/PE7 按键/开关另一脚全部接 GND
- [ ] 金属裸露点无搭接，电池固定牢靠

# 模块二　上电

## 2.1 生成与烧录（只做一次）

1. 打开 CubeMX，新建 STM32F407VETx 工程，严格按 `CUBEMX_配置与合并指南.md` 配置：
   SYS=Serial Wire、RCC=HSE 晶振、时钟树 168MHz、7 个定时器、3 路 USART、2 路 DMA、5 个 GPIO（User Label 必须一致）、NVIC 优先级表。
2. Generate 生成 Keil/CubeIDE 工程，先空工程编译一次，应为 **0 Error**。
3. 将 14 个业务文件复制进 `Core/Inc`、`Core/Src`（Keil 中把 7 个 .c 手动 Add 到工程组）。
4. main.c 插 3 行：
   `#include "app.h"`（Includes 区）、`App_Init();`（USER CODE 2）、`App_Tick();`（循环 USER CODE 3）。
5. 确认 `stm32f4xx_hal_conf.h` 内 `HAL_IWDG_MODULE_ENABLED` 已使能；Keil AC5 选 C99。
6. 编译 0 Error 后，ST-LINK 接 SWDIO/SWCLK/3.3V/GND 四线，烧录。

## 2.2 首次上电（低风险顺序）

1. **只接 ST-LINK（USB 供电）**，不接电池：按复位，PC8 的 LED 应以 0.5s 节奏**慢闪**，蜂鸣器不响。
   - 通过判据：LED 慢闪 = 程序正常运行，处于 IDLE。
2. 接 5V 降压和 BEC（仍不接 12V 电机动力）：LED 保持慢闪，量各电压轨：5.0V、3.3V。
3. 车轮保持悬空，最后合 12V 总开关：LED 仍慢闪，轮子静止，摸驱动板/电机无异常发热（30 秒）。
4. 断电，把车放地上。上电流程以后固定为：**先合总开关 → 再（树莓派供电已固定在线路中，待其启动约 30s）→ 短按 PE3 发车**。

## 2.3 指示灯/声音含义速查

| 现象 | 含义 | 你该做什么 |
|------|------|-----------|
| LED 0.5s 慢闪 | IDLE 待命，正常 | 短按 PE3 发车 |
| LED 常亮 | 自主运行中 | 观察车况 |
| LED 常亮 + 蜂鸣器长响 | 碰撞急停（EMERGENCY_STOP） | 排除障碍，**长按 PE3 满 1 秒**解除 |
| LED 快速乱闪/无规律 | 进了 Error_Handler 或反复复位 | 断电，查 HSE 晶振、供电、看门狗 |
| 完全不亮 | 没电/程序没跑/烧录失败 | 查电源、SWD、BOOT、晶振 |

# 模块三　调试（按顺序逐项标定）

> 总则：**先抬轮后落地、先单轮后整车、先开环后闭环、先本地后联调。**
> 全程用 Keil 调试模式（ST-LINK → Start Debug → Watch 窗口）监视下列变量：
> `debug_state`、`debug_ctrl_mode`、`debug_enc_delta[3]`、`debug_motor_target[3]`、
> `debug_motor_output[3]`、`debug_odom_x/y/theta`、`debug_distance_left/right`。
>
> 临时测试钩子：app.c 的 `ROBOT_STATE_IDLE` 分支里可临时加
> `DriveChassis(300,0,0);`（直行）/ `(0,0,1.0f)`（自转）/ `(0,300,0)`（横移），
> 短按发车即按该方式运动；**标定完务必删掉。**

## 3.1 电机转向验证

1. 抬轮，IDLE 分支临时钩子 `DriveChassis(300,0,0)`，发车。
2. 观察三个轮子转向是否符合全向轮"直行"方向（正前方运动时各轮滚向与安装角一致）。
3. 任一轮反转：断电对调该电机两根输出线（不要改代码）。
4. 判据：发直行命令时车有纯向前趋势；自转 `(0,0,1.0f)` 时三轮协调同向横摆。
5. 不通过：查 TB6612 的 IN 接线、STBY/PWM 使能脚。

## 3.2 编码器极性与刻度

1. 保持上一步钩子，手转/低速转动每个轮子，看 `debug_enc_delta[i]`：
   - 电机正向转时 delta 必须为**正**，反向为**负**；
   - 某轮符号相反：对调该编码器 A/B 两相；
   - delta 恒为 0：查编码器供电、A/B 接线、定时器 Encoder 模式、GPIO 上拉。
2. 刻度核对：在地上沿直线推车**恰好轮转 1 圈**（轮面做标记），
   单圈计数应接近 **60000**（=500×4×30）。
   - 偏差大：核对编码器线数/减速比，并修改 `kinematics.h` 中
     `KIN_ENCODER_PPR`、`KIN_MOTOR_GEAR_RATIO`。

## 3.3 PID 速度环整定（逐轮独立，负载一致）

目标单位：编码器计数/10ms；给阶跃目标约 500–800（约对应轮缘 170–270mm/s）。

1. 先设 `app.h`：`PID_KI=0`、`PID_KD=0`，`PID_KP=0.10`。
2. 观察 `debug_motor_target` 与 `debug_enc_delta`（全速运行后二者应近似重合）：
   - 实际远小于目标且无力 → Kp 每次 +0.1，直到响应迅速但出现轻微"来回抖"；
   - 取临界 Kp 的 0.6–0.7 倍作为最终 Kp。
3. 加入 Ki：从 0.005 起缓慢加，直到停下后稳态误差在 1 秒内消失且无持续低频摆动；
   静差消除即可，**宁小勿大**。
4. 加入 Kd：从 0.01 起加，抑制超调和急加速冲击；出现高频噪声抖动就回调。
5. 参考终值范围（供起点）：Kp 0.2–0.5，Ki 0.01–0.05，Kd 0.02–0.1；写入 `app.h`。
6. 判据：阶跃响应 0.3s 内跟上、超调 <10%、无震荡；三路分别整定后参数可统一。

## 3.4 运动学与里程计标定（落地进行）

1. **轮径标定**：地上贴 1000mm 刻度线。用临时钩子发直行（如 300mm/s），
   让车从 0 走到 `debug_odom_x`≈1000 时停车（或定时 3.3s），量实际距离 L。
   - 新轮径 = 66 × (L实测 / 1000)，改 `KIN_WHEEL_DIAMETER_MM`。
   - 重复 3 次，误差控制在 ±2%。
2. **直行纠偏**：车走不直 → 先确认 3.1/3.3 三轮一致性；机械上检查三轮接地压力；
   再在干净直线上跑，记录终点横向偏差。
3. **横移标定**：临时钩子 `(0,300,0)`，车应**纯侧向平移不转向**；
   若边移边转，说明某轮安装角或电机序号不对，核对 0°/120°/240° 物理布局。
4. **自转/底盘半径标定**：发 `(0,0,ω)` 运行 t=2π/ω 秒（理论自转 360°），
   在车顶画指针测实际转角 θ实：
   - 新底盘半径 R = 80 × (θ实 / 2π)，改 `OMNI_CHASSIS_RADIUS_MM`。
5. 判据：直行 1m 横偏 <30mm；自转 360° 误差 <10°；横移无明显转向。
   标定后 `debug_odom_x/y/theta` 即作为状态机"走没走到"的依据。

## 3.5 铲板与摄像头舵机标定

1. 临时把 `app.h` 中 `SERVO_ANGLE_INIT` 依次改为 `SHOVEL_ANGLE_DOWN/HOLD/UP` 的值
   （4500/7500/13500），每次烧录观察铲臂位置：
   - DOWN：铲板前缘贴地 2–3mm 且能滑入目标下方；
   - HOLD：托举 5–10mm 目标不滑落；
   - UP：可靠把目标推出铲面。
2. 按实物逐个微调三个角度宏（每 500 一档 ≈ 4.5°），完成后 INIT 改回 9000。
3. 摄像头舵机同理，使上电中位正对前方。
4. 判据：三档动作顺滑无堵转异响；舵机发卡先查 BEC 电压（带载 ≥4.8V）。

## 3.6 STP23L 激光测距校准

1. 上电后传感器对白墙，距离变量应在 200ms 内从 0xFFFF 变为有效值。
2. 依次在 **100 / 300 / 500 / 1000mm** 处放平板，读 `debug_distance_left/right`：
   - 误差应 <±3%；左右两个传感器分别测；
   - 恒 0xFFFF：查 230400 波特率、帧头、TX/RX 是否交叉、共地；
   - 数值跳动大：查供电、串口线远离动力线、确认置信度门限。
3. 判据：`APPROACH_STOP_DIST_MM=100` 的停车点对应铲板刚好贴住目标，
   不符就改 app.h 该宏。

## 3.7 按键与安全功能验证（必做，一项不过不许上场）

| 测试 | 操作 | 通过判据 |
|------|------|---------|
| 短按启动 | IDLE 下短按 PE3 | `debug_state`：0→1，LED 常亮 |
| 短按取消 | 运行中短按 PE3 | `debug_state`：→0，停车 |
| 碰撞急停 | 运行中把 PE4（或 PE7）短接 GND | 立即 `debug_state=8`，轮子停，蜂鸣器响 |
| 长按解除 | 急停后按住 PE3 满 1 秒 | 回 0，蜂鸣器停 |
| 看门狗 | 正常运行不干预 | 4s 内不应复位（不误触发） |

## 3.8 树莓派联调

1. 接线：树莓派 GPIO14(TX)→STM32 PA10(RX)，GPIO15(RX)→STM32 PA9(TX)，共地；
   Pi5 的 `/boot/firmware/config.txt` 加 `dtoverlay=uart0-pi5` 后重启。
2. 心跳：树莓派以 5Hz 发 HEARTBEAT；STM32 端不报错、`APP_REQUIRE_PI_HEARTBEAT` 可先置 0 单车调试，联调后置 1。
3. 视觉接管：发 MOTOR_COMMAND（±1000，TTL 250ms 连续发），
   看 `debug_ctrl_mode`=1，轮子按命令转；停止发送。
4. **拔线测试（关键安全项）**：运行中拔掉 TX 线，**250ms 内必须自动停车**。
5. 遥测：树莓派应每 100ms 收到 ENCODER（12 字节）和 DISTANCE（5 字节）帧。
6. 判据：全链路 CRC 无持续错误、无丢包导致的异常停车。

## 3.9 整车流程演练（空场）

按比赛实际节奏连续跑：
**IDLE → 短按 → 自转搜索 → 识别绿色普通物资（首个必须是普通物资）→ 接近停车 → 落铲 → 拖运 900mm → 抬铲释放 → 倒回 800mm → 再搜索**。
- 用 `TRANSPORT_DIST_MM / RETURN_DIST_MM` 把"安全区/搜索区"距离按你们实际场地方位修正；
- 演练伤员单独转运、危险浅蓝目标不接、一次最多 3 个物资三条规则；
- 连续 5 次无异常动作、无误铲、无超时卡死，方可进入对抗演练。

## 3.11 常见故障速查

| 现象 | 优先排查 |
|------|---------|
| LED 不亮 | 电池/开关/5V 降压；SWD 能否连接；HSE 是否 8MHz |
| 每隔约 4 秒自动复位 | 主循环被阻塞（中断里加了延时）、IWDG 未喂狗 |
| 电机完全不转 | TB6612 STBY/PWM 使能脚；12V；PWM 引脚与 CubeMX 通道 |
| 单个电机反转/编码器反号 | 对调电机动力线 / 编码器 AB 相 |
| 车该直行却原地转 | 轮序号与 0°/120°/240° 安装位不对应；某路 PID 失效 |
| 测距恒 0xFFFF | 波特率 230400、TX/RX 交叉、共地、传感器 5V 供电 |
| 树莓派收不到/发不出 | 交叉接线、UART overlay、串口权限 dialout/video、GND |
| 舵机抖/无力/树莓派重启 | 舵机独立 BEC 供电不足、动力与逻辑未共地、VM 电容缺失 |
| debug_state 频繁回 0 | 心跳超时（树莓派 HEARTBEAT 周期 >1s 或中断） |
