# 智能救援小車

大學生工程實踐與創新大賽「智能救援」賽道專案。小車透過視覺辨識場地中的不同顏色與幾何形狀目標，完成目標定位、接近、抓取與運送，模擬複雜環境下的自主救援任務。

本倉庫記錄小車的電控、視覺與機械抓取相關實現，以及從方案設計、軟硬體聯調到測試優化的過程。

## 專案特色

- **多色幾何體辨識**：根據目標的顏色與幾何特徵進行分類和定位。
- **視覺引導運動**：將影像中的目標位置轉換為小車的行駛與對準控制。
- **機械抓取救援**：使用機械抓完成目標抓取、搬運與指定區域放置。
- **電控協同**：整合底盤、感測器、視覺模組與抓取機構，完成任務狀態切換。
- **過程可追溯**：保存程式、接線與調試記錄，方便復現、排錯與後續改進。

## 整體架構

```text
		     +----------------+
		     |    視覺模組    |
		     |  影像擷取/辨識  |
		     +--------+-------+
				  |
			  目標位置與類別
				  v
+-------------+   +-------+--------+   +----------------+
| 底盤與感測器 |<->|   主控與任務邏輯 |<->|  機械抓與執行器 |
| 馬達/編碼器  |   | 導航/對準/狀態機 |   | 抓取/放置       |
+-------------+   +----------------+   +----------------+
```

系統工作流程如下：

1. 啟動各模組並完成感測器、相機與抓取機構初始化。
2. 擷取場地影像，依顏色和幾何特徵篩選目標。
3. 控制底盤靠近目標，並利用視覺回饋完成抓取前對準。
4. 控制機械抓閉合，確認目標已被抓取後運送至指定位置。
5. 放置目標並更新任務狀態，繼續搜尋下一個目標或結束任務。

## 功能模組

### 電控實現

- 底盤運動控制：前進、後退、轉向與定點對準。
- 馬達與執行器驅動：提供速度控制、方向控制及抓取動作控制。
- 感測器資料採集：為運動控制與狀態判斷提供回饋。
- 任務狀態機：管理搜尋、接近、抓取、搬運、放置與異常處理等狀態。
- 通訊與除錯：預留主控、視覺模組及其他控制板之間的資料交換介面。

### 視覺實現

視覺模組主要包含以下步驟：

1. 影像擷取與必要的影像預處理。
2. 在適當的色彩空間中分離目標顏色。
3. 透過輪廓、面積、外接矩形或其他幾何特徵篩選候選目標。
4. 計算目標中心、方向與類別。
5. 將辨識結果輸出給主控，作為底盤與機械抓的控制依據。

實際使用的閾值、相機參數與辨識規則，請以倉庫中的程式和調試記錄為準。

### 機械抓取

機械抓取模組負責完成：

- 抓取前姿態與位置對準。
- 抓閉合與目標固定。
- 運送過程中的目標保持。
- 到達指定區域後釋放目標。

抓取控制應配合目標尺寸、形狀、材質與機構行程進行校準，避免碰撞、漏抓或放置偏移。

## 開發與使用

由於不同版本可能使用不同的控制板、相機與開發工具，建議依下列順序進行：

1. 閱讀 `docs/` 中的硬體連接、供電與安全注意事項。
2. 分別完成視覺模組、底盤和機械抓的單體測試。
3. 確認主控與視覺模組的通信格式、座標方向及單位一致。
4. 在低速、無障礙環境中完成視覺對準與抓取校準。
5. 再進行完整救援流程測試，記錄辨識率、抓取成功率與任務耗時。

啟動指令、依賴套件和燒錄方式會隨實際實現更新，請以各子目錄中的說明文件為準。

## 測試重點

- 不同光照、背景和目標距離下的顏色辨識穩定性。
- 不同尺寸與姿態的幾何體辨識正確率。
- 視覺結果延遲或丟失時，小車的降級與停止行為。
- 小車接近目標時的定位誤差與碰撞風險。
- 機械抓對不同目標的抓取成功率與放置精度。
- 連續執行多個任務時的供電、通信與機構可靠性。

## 安全注意事項

- 首次聯調時應架空底盤或限制馬達輸出，確認方向後再落地運行。
- 調試機械抓時，請避開夾爪、連桿與馬達的活動範圍。
- 確認電池、驅動器與馬達的額定電壓電流相容，並保留急停或斷電方式。
- 修改控制參數後，先以低速和單步流程驗證，再進行整車測試。

## 後續規劃

- 完善視覺標定與目標距離估計。
- 提升弱光、反光和部分遮擋條件下的辨識穩定性。
- 優化底盤對準控制與抓取成功判斷。
- 補充自動化測試、測試數據與比賽現場復盤記錄。
